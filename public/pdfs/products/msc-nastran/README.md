# MSC Nastran PDF Resources

Place your PDF files for MSC Nastran in this directory.

## Required PDF Files

Add the following PDF files to this folder:

- [ ] `msc-nastran-brochure.pdf` - Product overview and marketing material
- [ ] `msc-nastran-datasheet.pdf` - Technical specifications summary
- [ ] `msc-nastran-user-guide.pdf` - Getting started documentation
- [ ] `msc-nastran-case-studies.pdf` - Real-world application examples
- [ ] `msc-nastran-white-paper.pdf` - In-depth technical analysis
- [ ] `msc-nastran-release-notes.pdf` - Latest version updates

## Optional Files

- [ ] `msc-nastran-training.pdf` - Training materials and tutorials
- [ ] `msc-nastran-specs.pdf` - Detailed technical specifications

## File Naming Rules

- Use lowercase letters
- Use hyphens (-) to separate words
- Include product name in filename
- Use `.pdf` extension

## After Adding Files

1. Verify files are named correctly
2. Check file sizes (max 10MB recommended)
3. Test download links on the website
4. Ensure PDFs are properly optimized for web

For more information, see the main README at `/public/pdfs/README.md`
